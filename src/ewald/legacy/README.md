# Legacy EWALD Reference Code

This folder preserves the exploratory EWALD implementation that existed before
the scikit-package-style rebuild.

Use it for stylistic guidance, old workflow clues, and migration reference.
Do not treat this folder as the active application surface. New UI and backend
work should live in the first-class package modules under `src/ewald/`.

Moved legacy areas:

- `analysis/`
- `apps/`
- `dataclass/`
- `dep/`
- `ui/`
- `yaml/`
- `debug.txt`
